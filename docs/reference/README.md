# Geetha Timbers reference (fill before Phase 0)

Claude Code matches the stack and look of whatever is in this folder.

- [ ] `package.json` files from Geetha Timbers (root + each app) → `docs/reference/geetha-timbers-package.json`
- [ ] Tailwind config and `globals.css` / theme file → `docs/reference/theme/`
- [ ] Folder structure: run `tree -L 3 -I node_modules > docs/reference/structure.txt` in that repo
- [ ] Its CLAUDE.md, if it has one → `docs/reference/geetha-timbers-CLAUDE.md`
- [ ] 5–10 screenshots → `docs/reference/screenshots/` (dashboard, list page, form, billing, login, mobile)
- [ ] Shared components or layout code worth reusing → `docs/reference/components/`

If this folder stays empty, the default stack in CLAUDE.md and defaults in docs/ui-guidelines.md are used.
